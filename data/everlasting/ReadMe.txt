***General Introduction***
This data set contains data collected during ageing tests in the Battery Testing Laboratory of VITO/EneryVille as part of the H2020 european project
Everlasting. 
Different ageing conditions were applied on commercial 18650 cells (Ni rich positive electrode and Si/Gr based negative electrode).
Each test condition was applied on two cells.
The cells were aged at different C-rates and different environmental temperatures (25°C and 45°C).
The cells were stored at 10; 70 and 90% SOC. These levels are defined from fresh cells and fixed (i.e. not updated with ageing).
The calendar test is regularly interrupted to run a reference test.
More details of the ageing tests can be found in the Everlasting deliverable
https://everlasting-project.eu/wp-content/uploads/2020/03/EVERLASTING_D2.3_final_20200228.pdf
And for more ageing data please check the Everlasting collection data.
 
***Purpose of the test campaign***
The purpose of these tests was to collect enough data to build a state of health model.

***Test equipment*** 
All tests were performed on a PEC battery tester

***Description of the data in this data set***
This data set includes data measured on cell level: time, voltage, current, temperature.
